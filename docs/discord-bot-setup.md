# GuildSync Discord bot setup

The bot source lives in `src/GuildSync.Bot`.

## Discord Developer Portal

1. Create a new Discord application named **GuildSync**.
2. Add a bot user in the **Bot** section.
3. Copy the bot token and store it only in the hosting provider as `GUILDSYNC_DISCORD_BOT_TOKEN`.
4. Never commit the token to GitHub or send it in chat.
5. Under OAuth2 installation, enable the `bot` and `applications.commands` scopes.
6. For the first test, invite the bot only to a private test server.

## Environment variables

- `GUILDSYNC_DISCORD_BOT_TOKEN`: private bot token.
- `GUILDSYNC_DISCORD_TEST_GUILD_ID`: optional test server ID. When present, commands register instantly in that server.
- `GUILDSYNC_API_URL`: central API URL. Current staging value: `https://clonar-dc-api.onrender.com`.

## Initial commands

- `/help`: command overview.
- `/plans`: reads the active plans from the central API.
- `/link`: reserved for the one-time account linking flow.
- `/license`: reserved for the linked license status.
- `/buy`: reserved for secure checkout after linking.

The first bot version intentionally does not request message-content access and uses only slash commands. The account linking design must use one-time codes generated by the authenticated desktop app; Discord users must never submit their GuildSync password to the bot.
