# GuildSync Discord community blueprint

This is the launch structure for the official GuildSync Discord server. Keep it small at first; empty channels make a community feel inactive.

## Roles

Order from highest to lowest:

1. **GuildSync Team** — owners and trusted administrators.
2. **Support** — can manage support threads and answer customers, but cannot manage billing secrets or server ownership.
3. **Customer** — granted after a verified GuildSync purchase or manual approval.
4. **Beta Tester** — users testing pre-release versions.
5. **Community** — standard verified members.
6. **GuildSync Bot** — bot role placed high enough to respond and manage only the channels it needs.

Use least-privilege permissions. Do not give Administrator to support staff or the bot unless a feature genuinely requires it.

## Categories and channels

### START HERE

- `#welcome` — one concise introduction and next steps.
- `#rules` — community rules, security warnings, and acceptable use.
- `#announcements` — releases, maintenance, and major changes; staff-only posting.
- `#status` — API, payment, and bot incident notices.
- `#pricing` — current plans and what each plan includes.
- `#downloads` — official GuildSync release links and SHA-256 verification instructions.

### SUPPORT

- `#support` — forum channel with tags: `Installation`, `Login`, `License`, `Payment`, `Discord`, `Cloning`, `Backup`.
- `#bug-reports` — forum channel with a required template: version, Windows version, reproduction steps, expected result, actual result.
- `#suggestions` — forum channel with voting enabled.
- `#known-issues` — staff-maintained list of confirmed problems and workarounds.

### COMMUNITY

- `#general` — normal community discussion.
- `#showcase` — users can share server structures created with GuildSync without exposing private information or credentials.
- `#beta-feedback` — visible to Beta Tester and staff roles.

### STAFF

- `#staff` — private coordination.
- `#support-queue` — private escalation notes; never paste passwords, tokens, payment credentials, or complete personal documents.
- `#payments-alerts` — optional private operational alerts containing order IDs and status only, not card or account details.
- `#audit-log` — Discord moderation actions and important server configuration changes.

## Recommended onboarding

1. Accept the rules.
2. Receive the **Community** role.
3. Read `#downloads` and `#pricing`.
4. Run `/help` to discover the official GuildSync bot commands.
5. Customers can run `/link` and connect the generated code inside the authenticated GuildSync app.

## Security notices to pin

- GuildSync staff will never request a Discord user token, Discord password, GuildSync password, Mercado Pago credential, complete card number, or recovery code.
- The only valid account-link code is generated by `/link`, expires after ten minutes, and is entered inside the GuildSync app.
- Download installers only from the official GuildSync GitHub release or an official future website.
- Verify the published SHA-256 before running an installer when possible.

## Launch sequence

1. Create the server and roles.
2. Create only the START HERE, SUPPORT, and STAFF categories initially.
3. Add the official GuildSync bot to a private test server first.
4. Test `/link`, `/license`, `/plans`, `/buy`, and `/unlink` with test accounts.
5. Add the bot to the official server after the complete flow passes.
6. Open the official server to beta testers before the public launch.
