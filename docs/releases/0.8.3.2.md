# GuildSync 0.8.3.2 — Recovery Release

## Correções

- Cadastro tenta o serviço central e, quando ele está realmente indisponível, cria uma conta local de pré-visualização usando o backend incluído no instalador.
- Contas locais pendentes podem abrir somente o modo de pré-visualização; isso não concede licença central nem acesso administrativo.
- O login tenta recuperar uma conta local existente quando o serviço central estiver indisponível.
- O cartão de login agora aumenta suavemente ao passar o mouse.
- Salvar Token não abre mais `MessageBox` nem dispara o som de alerta do Windows.
- `Load servers` não abre mais caixa modal em timeout ou erro.
- Quando o Discord rejeita ou não consegue consultar o Token, a interface abre um modo de pré-visualização claramente identificado.
- A pré-visualização permite analisar e simular o fluxo completo sem enviar nenhuma alteração ao Discord.
- Tokens aceitos de verdade continuam usando o motor real, preflight, backup preventivo, checkpoints e verificação.

## Release e empacotamento

- Versão nova usada para não reutilizar o número de um binário perdido.
- Desktop e backend publicados como Windows x64 autocontidos.
- CI bloqueia payloads e instaladores suspeitosamente pequenos.
- Smoke test abre o executável publicado antes da instalação.
- Smoke test instala silenciosamente e abre o executável instalado.
- A publicação da release deixa de ser opcional: falha na GitHub Release falha a pipeline.
- Release permanente inclui instalador, portátil, código-fonte, atualização e SHA-256.

## Limite honesto

O modo de pré-visualização serve para testar interface e fluxo com qualquer valor inserido. Alterações reais no Discord continuam exigindo uma credencial aceita pela API e permissões suficientes nos servidores envolvidos.
